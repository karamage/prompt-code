개인정보 처리방침

시행일: 2026년 10월 31일

Prompt Code(이하 “앱”)는 개인정보를 수집하지 않습니다. 앱이 다루는 모든 것은 사용자의 Mac에 저장되며, 개발자나 다른 누구에게도 전송되지 않습니다.

Mac에 저장되는 데이터

앱은 동작을 위해 다음 정보를 사용자의 Mac에 보관합니다.

  • 노트: 사용자가 고른 보관소 폴더에 .md 파일로 저장됩니다.
  • 설정과 창 상태: 테마, 단축키, 보관소 위치, 열려 있는 노트 등.
  • 클립보드 기록: 최근 복사한 텍스트 200개. 암호 관리자가 기록하지 말라고 표시한 복사 내용은 건너뜁니다. 메뉴 막대에서 언제든지 기록을 지울 수 있습니다.

Mac App Store 버전에서는 설정과 클립보드 기록이 macOS가 앱에 제공하는 전용 컨테이너(~/Library/Containers/dev.prompt-code.desktop)에 저장되며, 앱과 함께 삭제할 수 있습니다. 노트는 보관소 폴더에 그대로 남습니다.

네트워크

앱은 인터넷에 연결하지 않습니다. 앱 내부에서 창은 Mac 안에서만 작동하는 주소인 127.0.0.1을 통해 저장소와 통신하므로, 이 통신은 Mac 밖으로 나가지 않습니다.

앱이 하지 않는 일

계정, 분석, 광고, 충돌 보고가 없습니다. 개발자는 사용자의 노트, 클립보드 기록, 앱 사용 방식을 볼 수 없습니다.

손쉬운 사용 권한

앱은 빠른 붙여넣기에서 고른 내용을 사용자가 입력 중인 앱에 붙여넣기 위해 이 권한을 사용합니다. 권한이 허용되면 앱은 붙여넣기 키 입력(⌘V)만 보냅니다. 화면이나 다른 앱의 입력 내용은 읽지 않습니다.

변경

이 방침이 바뀌면 시행일과 함께 이 페이지를 업데이트합니다.
