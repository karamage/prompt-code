# Prompt Code

AI へのプロンプトを書いて、整理して、使い回すための macOS アプリです。Markdown エディタとスニペット管理を兼ねています。

Obsidian からは、書くことの気持ちよさを支える部分を取り入れました。自分のフォルダに置くただの Markdown ファイル、`[[リンク]]`、バックリンク、グラフ、コマンドパレットです。massCode からは、使い回しを速くする部分を取り入れました。フォルダ、タグ、お気に入り、ワンクリックでのコピーです。そのうえで、プロンプトに要るものを足しています。埋める変数、使い回す部品の埋め込み、モデルには送らない自分用のメモです。

## できること

- **変数**: `{{テーマ}}`、`{{読み手: エンジニア}}`（既定値つき）、`{{口調: 丁寧 | くだけた}}`（選択肢）と書きます。**使う** パネルが入力欄を作り、できあがったプロンプトを入力に合わせて表示します。`⌘↵` でコピーできます。
- **埋め込み**: `![[回答の形式]]` と書くと、コピーするときにそのノートの中身が入ります。人格の設定や出力の決まりを 1 か所にまとめて、どこにでも埋め込めます。
- **自分用のメモ**: `<!-- こう書く -->` はファイルに残り、コピーするときには消えます。
- **リンクとタグ**: 補完つきの `[[ノート]]` リンク、バックリンク、`#タグ`、グラフ（`⌘G`）があります。ノートの名前を変えると、そのノートへのリンクも書き換わります。
- **すばやい移動**: `⌘K` でノートを開き、`>` でコマンドを実行し、`⇧⌘F` ですべてのノートの中身を検索します。
- **ファイルはそのまま**: 保管庫は `.md` ファイルを入れたフォルダで、YAML の frontmatter（`tags`、`favorite`、`description`）を使います。ほかのアプリで編集しても、その変更をすぐに取り込みます。削除したノートは保管庫の中の `.trash/` に移ります。
- **どこからでもクイックペースト**: どのアプリにいても `⌃⌘V` で小さなウィンドウが開き、クリップボードの履歴とプロンプトから選べます。選ぶと、使っていたアプリにそのまま貼り付けます。変数のあるプロンプトは、その場で値を埋めてから貼り付けられます。
- **メニューバーのクリップボード履歴**: Prompt Code はメニューバーに常駐し、コピーした文字を残します（既定で 200 件）。パスワードマネージャが「隠す」印を付けたコピーは記録しません。最近の履歴とお気に入りのプロンプトは、メニューバーのメニューから 1 クリックで貼り付けられます。
- **書く・並べる・読む**: コードブロックに色が付く Markdown エディタと、読むための表示を切り替えられます。
- ライト・ダークのテーマ、5 色のアクセント、日本語と英語に対応しています。

データは Mac の外に出ません。アカウントも利用状況の送信も無く、ネットワークにも接続しません。

ほかのアプリに貼り付けるには、初回に macOS が **システム設定 › プライバシーとセキュリティ › アクセシビリティ** での許可を求めます。許可しなくても、クイックペーストはクリップボードへのコピーまで行うので、`⌘V` で貼り付けられます。ウィンドウを閉じてもメニューバーに残ります。終了はメニューバーのメニューか `⌘Q` から行います。

## キー操作

| キー | 動作 |
| --- | --- |
| `⌘K` | ノートを開く（`>` でコマンド） |
| `⌘N` / `⇧⌘N` | 新しいノート / 新しいフォルダ |
| `⇧⌘F` | すべてのノートを検索 |
| `⌘↵` | 変数を埋める。パネルの中ではコピー |
| `⇧⌘C` | いまの値でプロンプトをコピー |
| `⌘E` | 書く・読むを切り替え |
| `⌘\` | サイドバーの表示を切り替え |
| `⌘G` | グラフ |
| `⌘D` | ノートを複製 |
| `⌘⌫` | ノートをゴミ箱へ（通知から取り消せます） |
| `⌘,` | 設定 |
| `⌃⌘V`（どこからでも） | クイックペースト。設定で変えられます |
| `↵` / `⌘↵` / `⌘1`〜`⌘9` | クイックペーストで: 貼り付け / コピーだけ / その行を貼り付け |
| `⌘` + クリック | エディタの `[[リンク]]` を開く |

## ビルド

必要なもの: macOS 11 以降、[Bun](https://bun.sh)、Rust（`rust-toolchain.toml` のツールチェーンは rustup が自動で入れます）。

```sh
bun install
bun run app:build        # src-tauri/target/release/bundle/macos/Prompt Code.app
bun run app:dmg          # 署名なしの DMG
bun run release:mac      # 署名と公証を済ませた DMG（Developer ID が要ります。スクリプトの説明を参照）
```

ブラウザで開発する:

```sh
bun run build:client && bun run dev:server   # http://127.0.0.1:4721
bun run dev:client                            # :5183 で Vite のホットリロード（/api を中継）
bun run check                                 # 型チェック、lint、整形の確認、テスト
```

`dev:server` に `--vault <dir>` を渡すと、別のフォルダを開けます。設定は `~/.config/prompt-code/` に置きます（`PROMPT_CODE_HOME` で変えられます）。既定の保管庫は `~/PromptCode` です。

## つくり

アプリは意図して小さくしています。ディスク上で約 12 MB、裏側のサーバのメモリは約 40 MB です。

- ウィンドウは **Tauri** が OS の WebKit で作るので、ブラウザエンジンを同梱しません。
- 画面（React、CodeMirror 6）と API（Hono）は、`127.0.0.1` の空いているポートで待ち受けるローカルサーバが配ります。API を呼ぶには、アプリが起動のたびに作る合言葉が要ります。
- サーバは Bun や Node（約 60 MB）を同梱せず、QuickJS をもとにした約 6 MB の JavaScript ランタイム **[txiki.js](https://github.com/saghul/txiki.js)** で動かします。開発中は同じコードを Bun で動かし、違いは `src/server/runtime/` が吸収します。
- `scripts/build-server.ts` がサーバを 1 つのファイルにまとめ、チェックサムを確かめた txiki.js を Tauri の sidecar として置きます。

```
src/
  shared/   frontmatter、プロンプトの記法、ノートの情報（両側で使い、単体テストあり）
  server/   保管庫（一覧、監視、検索、ゴミ箱）、HTTP API、ランタイム（Bun / txiki.js）
  client/   React の画面、CodeMirror の拡張、Markdown の表示
src-tauri/  ネイティブの殻。sidecar を起動し、ウィンドウをそこへ向ける
```
