Prompt Code for macOS

Escribe un prompt una vez. Úsalo en cualquier sitio.

Un editor de Markdown y gestor de fragmentos para prompts de IA. Variables para rellenar, fragmentos reutilizables y una ventana de pegado rápido que funciona en cualquier app. Tus prompts siguen siendo archivos .md normales en tu Mac.

Descargar para Apple silicon Descargar para Intel

Última versión · macOS 11 o posterior · Firmada y notarizada · Gratis y de código abierto (MIT)

01 / Sintaxis de prompts

Los prompts son plantillas,
no texto que vuelves a escribir.

Tres pequeñas extensiones de Markdown convierten una nota en algo que rellenas y copias. Todo lo demás es Markdown normal.

Explica {{topic}} a
{{audience: engineers}} con un
tono {{tone: friendly | formal}}.

Variables

Campos simples, valores por defecto o una lista de opciones. El panel Usar los convierte en campos y muestra el prompt terminado mientras escribes. ⌘↵ lo copia.

02 / Pegado rápido

Tus prompts, en cualquier app donde escribas.

Pulsa ⌥⌘V en cualquier sitio. Una ventana pequeña muestra tu historial del portapapeles y tus prompts. Elige uno y se pega donde estabas escribiendo.

  • Rellena primero. En los prompts con variables puedes escribir los valores ahí mismo antes de pegar.
  • Historial del portapapeles en la barra de menús. Guarda las últimas 200 copias. Las copias que los gestores de contraseñas marcan como ocultas nunca se registran.
  • Todo con el teclado. ↵ pega, ⌘↵ solo copia, ⌘1–⌘9 pegan una fila.

03 / Funciones

Lo mejor de una app de notas
y de un gestor de fragmentos.

Enlaces, retroenlaces, un grafo y una paleta de comandos para escribir. Carpetas, etiquetas, favoritos y copia con un clic para reutilizar.

Enlaces y etiquetas

Enlaces [[Nota]] con autocompletado, retroenlaces, #etiquetas y una vista de grafo. Al renombrar una nota se actualizan los enlaces que apuntan a ella.

Navegación rápida

⌘K salta a cualquier nota, > ejecuta comandos y ⇧⌘F busca en el texto de todas las notas.

Tus archivos, tal cual

Una bóveda es una carpeta de archivos .md con frontmatter YAML. Edítalos en cualquier app y los cambios aparecen al instante.

Escribir y leer

Un editor de Markdown con bloques de código resaltados y una vista de lectura a la que cambias con ⌘E.

Nada sale de tu Mac

Sin cuenta, sin telemetría, sin peticiones de red. Las notas eliminadas van a .trash/ dentro de la bóveda.

Pequeña y nativa

Unos 12 MB en disco. Hecha con Tauri sobre el WebKit del sistema. Temas claro y oscuro y cinco colores de acento. La interfaz de la app está en inglés y japonés.

05 / Descarga

Consigue Prompt Code.

Elige el DMG para tu Mac, ábrelo y arrastra Prompt Code a Aplicaciones. Al abrirla por primera vez se muestra una breve guía.

Apple silicon M1 y posteriores Intel

Última versión · Todas las versiones y sumas de verificación

  • Firmada con un Developer ID y notarizada por Apple, así que se abre sin advertencias. Requiere macOS 11 o posterior.
  • Para pegar en otras apps, macOS te pide que permitas Prompt Code en Ajustes del Sistema › Privacidad y seguridad › Accesibilidad. Sin ese permiso, el pegado rápido igualmente copia el texto para que lo pegues con ⌘V.
  • Al cerrar la ventana, Prompt Code sigue en la barra de menús. Sal desde el menú de la barra de menús o con ⌘Q.

06 / Preguntas

Preguntas.

¿Dónde se guardan mis prompts?
En una carpeta de archivos Markdown, ~/PromptCode por defecto; puedes elegir otra en Ajustes. Puedes hacer copias de seguridad, sincronizarla o ponerla en git como cualquier otra carpeta.
¿Envía mis prompts a algún sitio?
No. Prompt Code no tiene cuenta ni telemetría y no hace peticiones de red. Su servidor local solo escucha en 127.0.0.1 y exige un token generado al abrir la app.
¿Puedo usarla con mi bóveda de Obsidian?
Lee archivos .md normales con frontmatter YAML y [[enlaces]], así que puedes elegir como bóveda cualquier carpeta de notas Markdown en Ajustes (⌘,).
¿Con qué herramientas de IA funciona?
Con todas. Prompt Code copia o pega el texto terminado, así que funciona igual con apps de chat, IDE, terminales y navegadores.
¿Cuánto cuesta?
Nada. Es de código abierto con licencia MIT.
