Prompt Code for macOS

Write a prompt once. Use it everywhere.

A Markdown editor and prompt snippet manager. Write AI prompt templates with fill-in variables and reusable fragments, and paste them from a quick paste window that works in any app. Your prompts stay plain .md files on your Mac.

Download for Apple silicon Download for Intel

Latest release · macOS 11 or later · Signed and notarized · Free and open source (MIT)

01 / Prompt syntax

Prompts are templates,
not text you retype.

Three small additions to Markdown turn a note into an AI prompt template you fill in and copy. Everything else is plain Markdown.

Explain {{topic}} to
{{audience: engineers}} in a
{{tone: friendly | formal}} tone.

Variables

Plain fields, defaults, or a list of choices. The Use panel turns them into inputs and shows the finished prompt as you type. ⌘↵ copies it.

Embeds

Keep a persona or an output contract in one note and pull it into any prompt. It is filled in when you copy.

Notes to yourself

HTML comments stay in the file and are removed on copy, so the model never sees them.

02 / Quick paste

Your prompts, in whatever app you are typing.

Press ⌥⌘V anywhere. A small window shows your clipboard history and your prompts. Pick one and it is pasted where you were typing.

  • Fill in first. Prompts with variables let you enter the values right there before pasting.
  • Clipboard history in the menu bar. Keeps the last 200 copies. Copies that password managers mark as concealed are never recorded.
  • Keyboard all the way. ↵ pastes, ⌘↵ only copies, ⌘1–⌘9 paste a row.

03 / Features

The good parts of a notes app
and a snippet manager.

Links, backlinks, a graph and a command palette for writing. Folders, tags, favorites and one-click copy make it a prompt snippet manager.

Links and tags

[[Note]] links with autocomplete, backlinks, #tags and a graph view. Renaming a note rewrites links to it.

Fast navigation

⌘K jumps to any note, > runs commands, ⇧⌘F searches the text of every note.

Your files, as they are

A vault is a folder of .md files with YAML frontmatter. Edit them in any app and the changes show up live.

Write and read

A Markdown editor with highlighted code blocks, and a reading view you switch to with ⌘E.

Nothing leaves your Mac

No account, no telemetry, no network requests. Deleted notes go to .trash/ inside the vault.

Small and native

About 12 MB on disk. Built with Tauri on the system WebKit. Light and dark themes, five accents, English and Japanese.

05 / Download

Get Prompt Code.

Choose the DMG for your Mac, open it, and drag Prompt Code into Applications. A short guide opens on first launch.

Apple silicon M1 and later Intel

Latest release · All releases and checksums

  • Signed with a Developer ID and notarized by Apple, so it opens without warnings. Requires macOS 11 or later.
  • To paste into other apps, macOS asks you to allow Prompt Code under System Settings › Privacy & Security › Accessibility. Without it, quick paste still copies the text for you to paste with ⌘V.
  • Closing the window keeps Prompt Code in the menu bar. Quit from the menu bar menu or with ⌘Q.

06 / FAQ

Questions.

Where are my prompts stored?
In a folder of Markdown files, ~/PromptCode by default; pick another one in Settings. You can back it up, sync it, or put it in git like any other folder.
Does it send my prompts anywhere?
No. Prompt Code has no account and no telemetry, and it makes no network requests. Its local server only listens on 127.0.0.1 and requires a token generated at launch.
Can I use it with my Obsidian vault?
It reads plain .md files with YAML frontmatter and [[links]], so you can choose any folder of Markdown notes as the vault in Settings (⌘,).
How is it different from a general snippet manager?
A general snippet manager pastes fixed text. Prompt Code is built for AI prompt templates: variables with defaults and choices become fields you fill in before pasting, shared fragments are embedded when you copy, and notes to yourself are removed so the model never sees them.
Which AI tools does it work with?
Any of them. Prompt Code copies or pastes finished text, so it works with chat apps, IDEs, terminals and browsers alike.
How much does it cost?
Nothing. It is open source under the MIT License.
