Prompt Code for macOS

Écrivez un prompt une fois. Utilisez-le partout.

Un éditeur Markdown et gestionnaire d’extraits pour les prompts d’IA. Variables à remplir, fragments réutilisables et une fenêtre de collage rapide qui fonctionne dans n’importe quelle app. Vos prompts restent de simples fichiers .md sur votre Mac.

Télécharger pour Apple silicon Télécharger pour Intel

Dernière version · macOS 11 ou ultérieur · Signée et notarisée · Gratuite et open source (MIT)

01 / Syntaxe des prompts

Les prompts sont des modèles,
pas du texte à retaper.

Trois petits ajouts à Markdown transforment une note en quelque chose que l’on remplit et que l’on copie. Tout le reste est du Markdown ordinaire.

Explique {{topic}} à
{{audience: engineers}} sur un
ton {{tone: friendly | formal}}.

Variables

Champs simples, valeurs par défaut ou liste de choix. Le panneau Utiliser les transforme en champs de saisie et affiche le prompt final au fil de la frappe. ⌘↵ le copie.

Intégrations

Gardez un persona ou un format de sortie dans une note et intégrez-le dans n’importe quel prompt. Il est inséré au moment de la copie.

02 / Collage rapide

Vos prompts, dans l’app où vous êtes en train d’écrire.

Appuyez sur ⌥⌘V où que vous soyez. Une petite fenêtre affiche l’historique du presse-papiers et vos prompts. Choisissez-en un, il est collé là où vous écriviez.

  • Remplir d’abord. Pour les prompts avec variables, saisissez les valeurs directement dans la fenêtre avant de coller.
  • Historique du presse-papiers dans la barre des menus. Conserve les 200 dernières copies. Les copies que les gestionnaires de mots de passe marquent comme masquées ne sont jamais enregistrées.
  • Tout au clavier. ↵ colle, ⌘↵ copie seulement, ⌘1–⌘9 collent une ligne.

03 / Fonctions

Le meilleur d’une app de notes
et d’un gestionnaire d’extraits.

Liens, rétroliens, graphe et palette de commandes pour écrire. Dossiers, tags, favoris et copie en un clic pour réutiliser.

Liens et tags

Liens [[Note]] avec autocomplétion, rétroliens, #tags et vue en graphe. Renommer une note met à jour les liens qui y mènent.

Navigation rapide

⌘K ouvre n’importe quelle note, > lance des commandes, ⇧⌘F cherche dans le texte de toutes les notes.

Vos fichiers, tels quels

Un coffre est un dossier de fichiers .md avec un frontmatter YAML. Modifiez-les dans n’importe quelle app, les changements apparaissent aussitôt.

Écrire et lire

Un éditeur Markdown avec coloration des blocs de code, et une vue de lecture accessible avec ⌘E.

Rien ne quitte votre Mac

Pas de compte, pas de télémétrie, aucune requête réseau. Les notes supprimées vont dans .trash/ à l’intérieur du coffre.

Légère et native

Environ 12 Mo sur le disque. Construite avec Tauri sur le WebKit du système. Thèmes clair et sombre, cinq couleurs d’accent. L’interface de l’app est en anglais et en japonais.

05 / Téléchargement

Obtenir Prompt Code.

Choisissez le DMG adapté à votre Mac, ouvrez-le et faites glisser Prompt Code dans Applications. Un court guide s’ouvre au premier lancement.

Apple silicon M1 et ultérieurs Intel

Dernière version · Toutes les versions et sommes de contrôle

  • Signée avec un Developer ID et notarisée par Apple : elle s’ouvre sans avertissement. Nécessite macOS 11 ou ultérieur.
  • Pour coller dans d’autres apps, macOS vous demande d’autoriser Prompt Code dans Réglages Système › Confidentialité et sécurité › Accessibilité. Sans cette autorisation, le collage rapide copie tout de même le texte, que vous collez avec ⌘V.
  • Fermer la fenêtre laisse Prompt Code dans la barre des menus. Quittez-la depuis le menu de la barre des menus ou avec ⌘Q.
Compiler depuis les sources

06 / FAQ

Questions.

Où sont stockés mes prompts ?
Dans un dossier de fichiers Markdown, ~/PromptCode par défaut ; vous pouvez en choisir un autre dans les Réglages. Sauvegardez-le, synchronisez-le ou mettez-le dans git comme n’importe quel dossier.
Mes prompts sont-ils envoyés quelque part ?
Non. Prompt Code n’a ni compte ni télémétrie et n’effectue aucune requête réseau. Son serveur local n’écoute que sur 127.0.0.1 et exige un jeton généré au lancement.
Puis-je l’utiliser avec mon coffre Obsidian ?
Elle lit de simples fichiers .md avec frontmatter YAML et [[liens]] : vous pouvez donc choisir comme coffre n’importe quel dossier de notes Markdown dans les Réglages (⌘,).
Avec quels outils d’IA fonctionne-t-elle ?
Avec tous. Prompt Code copie ou colle le texte final : il fonctionne aussi bien avec les apps de chat, les IDE, les terminaux que les navigateurs.
Combien ça coûte ?
Rien. C’est un logiciel open source sous licence MIT.
